Importer une liste

Collez les lignes de votre feuille de suivi, en-tête comprise — tabulations, points-virgules ou virgules, peu importe. Colonnes indispensables : id (référence de suivi, ex. ECH2_01 — sans elle, pas de mot de passe), nom, prenom et compte_teams — compte Teams TMK au format prenom.nom@…, ou adresse fournie par l'entreprise cliente, recopiée telle quelle. Facultatives : civ (M ou Mme), telephone, date_naissance, email_personnel.

L'import écrit directement : il n'y a pas de brouillon. Le compte rendu s'affiche ensuite, ligne par ligne.

Saisir un stagiaire

Sans feuille de suivi — par exemple pour une entreprise qui utilise l'outil avec ses propres stagiaires. La référence est proposée au numéro suivant du groupe : elle entre dans le mot de passe, vous pouvez la modifier avant d'ajouter.

Le stagiaire est inscrit tout de suite ; son compte se crée ensuite dans la carte « Comptes de connexion ».

Comptes de connexion

Le compte est l'adresse Teams du stagiaire ; le mot de passe se calcule à partir de son nom et de son identifiant de suivi. Regardez d'abord ce qui serait fait.

Ajouter un membre du personnel

Le compte de connexion est créé ici, avec un mot de passe affiché une seule fois : notez-le pour le transmettre. Si l'adresse a déjà un compte, il est simplement rattaché au personnel, avec son mot de passe actuel.

Personnel

Assistant du cours

Choisissez les modules sur lesquels les stagiaires peuvent poser leurs questions à l'assistant. Il répond uniquement à partir des supports du module, sur les vidéos, mémos et exemples ; il est toujours fermé pendant les exercices, les évaluations et les rappels. Un nouveau module est fermé par défaut.

Questions des stagiaires à l'assistant

Les questions posées à l'assistant du cours sur vos séances. Répondez à celles que les stagiaires vous ont transmises : votre réponse apparaît dans « Mes questions » sur leur portail. En cochant « Ajouter à l'assistant », elle devient aussi un support du module, que l'assistant pourra citer aux groupes suivants. Repérez enfin les questions restées sans réponse : elles signalent souvent un point qui manque dans le cours.
